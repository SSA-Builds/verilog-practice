# Verilog Practice

A hands-on journey into Digital Design, Verilog HDL, RTL Design, and functional simulation.

## About

This repository documents my learning and practical implementation
of digital hardware concepts using Verilog HDL.

## Topics Covered

- Number Systems and Boolean Algebra
- Combinational Logic Circuits
- Sequential Logic Circuits
- Finite State Machines (FSMs)
- RTL Design and Simulation
- Verilog Testbenches

## Tools & Technologies

- Verilog HDL
- Icarus Verilog
- GTKWave
- Visual Studio Code
- Git & GitHub

## Repository Structure

- `basics/` – Verilog fundamentals
- `combinational/` – Combinational circuit designs
- `sequential/` – Sequential circuit designs
- `testbenches/` – Simulation testbenches
- `waveforms/` – Simulation waveform files
- `notes/` – Digital logic and Verilog notes

## Current Progress

Currently working on Verilog fundamentals and combinational
circuit implementations.

More RTL projects and verification exercises will be added
as I progress.
